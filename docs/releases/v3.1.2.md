# Universal Extractor 2 v3.1.2

This release adds Game Extractor Basic as an optional fallback for game archives that UniExtract's existing handlers cannot open.

## What's new

- Added optional Game Extractor Basic command-line extraction support.
- Game Extractor is deliberately tried late: dedicated handlers, GARbro, QuickBMS, extension-specific routes and the generic 7-Zip probe keep priority.
- Added Game Extractor to the Plugin Manager, using the public upstream Basic release rather than files copied from the paid Full edition.
- Game Extractor extraction is only accepted when its CLI reports completion and UniExtract detects real output.
- Added documentation covering installation, routing, coverage and the Basic/Full licensing boundary.

## Coverage

The integration calls Game Extractor Basic's own archive reader/export pipeline. That means archive plugins loaded by the installed Basic package are available to UniExtract without duplicating thousands of per-game handlers in AutoIt.

Watto's current comparison lists both Basic and Full as supporting archive reading for 5,700+ games and file extraction. UniExtract uses that shared extraction path. It does **not** bundle or claim the Full edition's additional preview, editing, archive-writing or conversion features.

The public v3.16.0008 source tree reviewed for this work contains 1,957 archive plugin source files; the reviewed 3.16-generation plugin set declares 1,058 distinct file extensions. There is significant overlap with UniExtract's existing 7-Zip, GARbro and QuickBMS support, so the practical gain is mainly obscure and game-specific archive variants.

## Packaging

Game Extractor is not bundled in the standard UniExtract ZIP because its normal distribution includes a Java runtime and would substantially increase the package size. Install it separately through UniExtract's Plugin Manager when needed.

The normal UniExtract helper package remains based on gvp9000 v3.0.6.
