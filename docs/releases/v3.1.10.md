# Universal Extractor 2 v3.1.10

Integrates gvp9000 v3.0.12 while retaining this fork's FreeArc, Unicode detector,
header-confidence, silent-mode and updater behavior.

- Fix five timeout comparisons that multiplied an already-millisecond value by 1000.
- Reset probe and failure state on each file/retry. Stop legacy hint replay after definitive corruption or password failure.
- Restore executable Inno/InstallExplorer and generic 7-Zip fallbacks; use dedicated NSIS/RAR SFX routes and nonfatal detector-confirmed Inno/InstallShield attempts.
- Recognize InstallShield cabinets by signature while preserving legacy multipart cabinet handling.
- Run legacy TrID/Unix hints earlier for unclassified files without bypassing verified headers, protected installer contexts, or bundled game-audio decoding.
- Import CreateInstall plugins from runtime selections, flat archives or nested packages. Reject incomplete/ambiguous packages before copying, and fix temporary directory names on Windows.
- Correct the arc_convert plugin filename and improve QuickBMS/WCX reporting when runtime logs are disabled.
- Refresh 7-Zip to 26.05, innounp to 2.71.2, PEA to 1.34, SQLite to 3.54.1, lconvert to 5.15.19, DiE definitions and TrID to 22,576 definitions.

Helper downloads and the v3.0.12 base are SHA-256 pinned. SQLite retains an x86 shell
and both DLL architectures. Bio.cs stays at the existing tested 2.5.0 runtime.
The new regression suite covers CAB identification, retry state, fallback behavior,
and inert CreateInstall package imports. Format-specific testing cannot cover every
historical installer variant supported by the specialist helpers.
