# Universal Extractor 2 v3.1.4

This release adds proprietary game-audio decoding, refreshes the ACE extractor, and strengthens reproducibility and auditing of the helper package. It builds on v3.1.3's maintained-helper refresh.

## What's new

- **Game audio — vgmstream r2117 (x86/x64):** A low-priority fallback for selected proprietary game-audio extensions. Normal archive handlers, installed Game Extractor and other existing routes take priority. On supported inputs it can decode the default stream into a WAV file. It does **not** claim every subsong or bank entry is extracted.
- **ACE — acefile 0.6.14:** Replaces the old 0.6.11 Windows helper with a self-contained x86 console executable reproducibly built from SHA-256-pinned upstream Python source and pinned PyInstaller tooling. Preserves the existing UniExtract extraction command.
- **Full binary audit:** Every file in the packaged `bin` tree receives a relative path, size, SHA-256, and available PE architecture/version information in `BIN-INVENTORY.csv`. `BIN-EXECUTABLES.csv` focuses on the actual helper executables; `BIN-INVENTORY-SUMMARY.txt` gives counts and review classifications.
- **Stronger supply-chain checks:** The inherited gvp9000 v3.0.6 helper ZIP and refreshed upstream overlays are SHA-256 verified. Fork-managed files, including acefile and vgmstream, are protected from being downgraded by the legacy helper update feed.
- **Packaging improvements:** Required helper files and final release assets are validated; generated inventories can also be downloaded from the Windows build's GitHub Actions artifacts.

## Validation

The Windows PR #9 CI successfully built and packaged the updated app. The packaged smoke tests passed:

- Normal ZIP extraction and ZIP extraction with a Unicode filename
- A synthetic ADX sample decoded to a RIFF/WAVE output via vgmstream
- A real upstream ACE archive: all 268 entries passed integrity checking, then 247 files were successfully extracted by the new acefile executable

The release commit is also subject to its own Windows build and packaged smoke tests before its GitHub Actions workflow publishes the assets.

## Compatibility and known limits

- The full package still incorporates the gvp9000 v3.0.6 helper set for specialist and legacy extractors. **Not every helper binary is updated.** See `docs/HELPER-AUDIT.md`.
- The **Bio.cs 2.6.0 ABI compatibility candidate** was developed and verified separately (PR #10), but the bundled `Bio.cs.dll` remains **2.5.0** until dependent extractors are regression-tested.
- file/libmagic 5.46 and its matching `magic.mgc` are retained until a tested Windows replacement is ready. 32-bit fallback compatibility is preserved.
- Game Extractor Basic remains an optional plugin, not part of the standard ZIP.

## Files

The release includes `UniExtract2-v3.1.4.zip`, the standalone UniExtract and updater executables, and `SHA256SUMS.txt`. The ZIP includes the binary inventory CSVs and third-party license notices.
