# Universal Extractor 2 v3.1.5

Hotfix for an incorrect FreeArc installer-data detection path found in v3.1.4.

## Fixed

- **Verified FreeArc header wins:** For a file beginning with `41 72 43 01` (`ArC\\x01`), UniExtract now identifies **FreeArc** using its magic bytes rather than relying on the extension or on fuzzy game-resource detection. This check runs before general `.bin` 7-Zip/ISO probing and before GARbro.
- **Avoid false PD/KAAS game archives:** GARbro's PD/KAAS recognizer is signatureless and generates synthetic numbered names. That low-confidence result is rejected on `.bin` files. Numbered installer sidecars with adjacent matching executables and independently corroborated FreeArc scanner results bypass broad game/resource scanners.
- **Accurate status and tool reporting:** A failed FreeArc extraction does not silently fall through to an unrelated game format. FreeArc/unarc and GARbro are recorded as the extractor when they really succeed, instead of stale ZIP or 7-Zip summaries.
- **Regression coverage:** CI executes both AutoIt function-level tests for magic bytes/sidecars and a packaged end-to-end negative smoke test ensuring an invalid `ArC\\x01` archive cannot be mistaken for a successful GARbro extraction.
- **Helper reproducibility:** TrID's upstream rolling database hash is revalidated and pinned in packaging, with an exact definition-count assertion.

## What this does *not* do

The bundled `unarc.exe` cannot necessarily decode proprietary FreeArc repack compression/encryption configurations. A separate user-supplied CODEX-style unpacker using `FreeArcExtract` succeeded with `Password=ABC`, but that executable and DLL are not redistributed or automatically run by UniExtract. v3.1.5 **corrects identification and safe routing**; it does not promise support for every password-protected or custom-codec archive.

Existing game-specific extractors, 32-bit support, and other v3.1.4 features remain available.

Source investigation and tests: [Installer BIN guard](https://github.com/wefalltomorrow/UniExtract2/blob/master/docs/INSTALLER-BIN-GUARD.md).
