# Universal Extractor 2 v3.1.7

This release adds an optional external FreeArc backend for custom installer
archives that the bundled decoder cannot extract, and corrects extraction
reports when an attempted backend fails.

## Changes

- External FreeArc support is disabled by default. Users must explicitly
  enable it and select their own trusted wrapper, DLL and configuration.
  No external unpacker is bundled or automatically discovered.
- The built-in FreeArc decoder is tried first. The optional fallback preserves
  the original configuration and stages output separately. It requires a zero
  process exit, regular output files and a safe directory rename into a new or
  empty destination. Existing output is never merged or overwritten.
- Timeout, cancellation and child-process cleanup limit failed attempts.
  Passwords stay out of command arguments and diagnostic reports; both wrapper
  output streams are discarded. Temporary configuration is cleaned up on
  normal completion.
- Failed extraction no longer gets a successful HTML badge merely because
  warnings exist. Reports distinguish attempted extractors from the backend
  that successfully committed output.
- Successful reports retain the actual success status even when the log
  filename uses an archive format label. Packaged tests check success badges
  for both built-in and external FreeArc extraction.
- TrID definitions use the checksum-verified release snapshot with 22,456
  definitions, avoiding the rolling-download checksum failure. The innounp
  download is pinned to an upstream commit with its existing payload checksum.
- Windows regression and packaged smoke tests cover normal and malformed
  FreeArc, external fallback success and failure, Unicode paths, config
  encodings, existing output, cancellation, timeouts, cleanup and reporting.

## Limits

The external wrapper runs with the user's permissions; staging and process
jobs are not a security sandbox. Only enable a wrapper you deliberately trust.
Different custom archives may require different codecs or settings. File
presence and a zero exit alone do not prove complete or correct extraction.

The separate file/libmagic 5.48 candidate (PR #13) is not included.
See [external FreeArc documentation](../FREEARC-EXTERNAL-BACKEND.md) for setup
and detailed limitations.
