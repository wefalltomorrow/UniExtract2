# Universal Extractor 2 v3.1.0

This is the first release from the wefalltomorrow fork.

It starts from gvp9000's current 2026 UniExtract2 work and adds the fork cleanup/fixes reviewed in PR #1.

## Main changes

- current Detect It Easy / Exeinfo PE / PEiD detection pipeline
- newer Inno Setup, InstallShield, WiX/Burn, Setup Factory, VISE/Gentee and NSIS handling
- updated 7-Zip, UnRAR, innounp, TrID, UPX, SQLite, lessmsi and related helper integration
- improved batch queue, multipart and context-menu behavior
- password-protected PDF support through qpdf
- ECM and ARJ Software JAR support
- FreeSpace / FreeSpace 2 VP directory-structure fix
- copied/quoted path handling from upstream PR #408
- improved true-silent startup/first-run behavior
- MHTML extension recovery
- cleaned repository/update metadata for this fork
- corrected GPLv2/About metadata
- repeatable Windows AutoIt build and release packaging

## Packaging

The full release ZIP uses the helper set from gvp9000 v3.0.4 as its binary base, then overlays the executables, definitions, languages, documentation and metadata from this repository.

Helper-file updates still use gvp9000's maintained helper feed for now. The main UniExtract executable is not allowed to update from that feed.

A standalone `UniExtract.exe` is included as a release asset so this fork's updater can fetch the latest stable executable directly from GitHub.
