# Universal Extractor 2 v3.1.3

This release refreshes the actively maintained extraction/detection helpers without throwing away the old specialist tools that still give UniExtract its broad compatibility.

## Updated helpers

The release pipeline now refreshes and validates:

- 7-Zip 26.04 (x86/x64)
- qpdf 12.4.2
- UPX 5.2.1
- MediaInfoLib 26.10
- Exeinfo PE 0.1.0.0
- Champollion 1.3.2
- PEA 1.33
- GNU gettext `msgunfmt` 1.0
- innounp 2.71.1
- TrID definitions dated 2026-10-08 (22,425 definitions)
- UnRAR 7.23 x64
- CHDMan 0.289 x64
- SQLite 3.53.4
- Asar7z 1.5
- eDecoder 1.20.8
- Iso7z 1.8.7
- Py7z 1.2.1

Exeinfo PE is now isolated under `bin\Exeinfo\` so its own package files do not collide with the old PEiD support files.

## Reproducible helper overlay

The full ZIP still begins with the gvp9000 v3.0.6 helper bundle as a compatibility base for legacy tools. A new maintained overlay then downloads known upstream packages, validates pinned SHA-256 values and reported versions, and replaces the helpers listed above before the final release ZIP is created.

The older gvp9000 helper feed is prevented from replacing files maintained by this overlay, avoiding accidental downgrades after installation.

## Compatibility over version-chasing

Not every old-looking helper was replaced.

Detect It Easy 3.21 is still the latest published stable Windows release. Several other helpers either have no newer official Windows binary or are tied to old compatibility-sensitive runtimes. The release keeps those deliberately rather than swapping in untested builds simply to increase a version number.

The reasoning and remaining exceptions are documented in `docs/HELPER-AUDIT.md`.

## Validation

The Windows release workflow:

- builds all three UniExtract executables and verifies version 3.1.3.0,
- validates refreshed helper downloads and versions,
- verifies refreshed 7-Zip format plugins load on x86 and x64,
- packages the complete helper-backed build,
- runs normal ZIP extraction,
- runs Unicode-filename ZIP extraction,
- publishes SHA-256 hashes for the release assets.

Game Extractor Basic remains an optional plugin and is not bundled into the standard package.
