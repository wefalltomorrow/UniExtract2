# Universal Extractor 2 v3.1.6

This release improves the way UniExtract2 identifies files, preventing permissive game and ISO extractors from overriding stronger format evidence.

## Fixed

- **File signatures take precedence over filename extensions and extractor guesses.** A central header check recognizes FreeArc, 7-Zip, ZIP, RAR, gzip, bzip2, xz and common media/document formats.
- **Safer extraction priority.** Native archive handlers run before broad ISO/GARbro/QuickBMS/TotalObserver guesses. Matching extension-specific handlers and genuine game-specific BMS routes remain available.
- **No unrelated fallback for verified archives.** Failure to extract a recognized format no longer results in a speculative claim that it is an unrelated game archive.
- **Reject ambiguous detection results.** QuickBMS and related handlers require credible positive file listings. GARbro's signatureless PD/KAAS guess is rejected outside the native `.pd` extension.
- **More reliable format reports.** A verified header cannot be silently overwritten by a later low-confidence detection result. PDF, audio and video handlers remain available where appropriate.
- **Broader Windows regressions.** The build checks binary signatures, renamed extensions, invalid/probe outputs, the FreeArc installer-sidecar regression, and packaged extraction behavior.

## Limitations

Format recognition and decompression support are separate. In particular, the bundled FreeArc helper may not support custom game-repack codecs/passwords even when FreeArc is identified correctly.

This release does **not** include the separate draft file/libmagic 5.48 upgrade (PR #13); that remains under review.

See [detection confidence policy](https://github.com/wefalltomorrow/UniExtract2/blob/master/docs/DETECTION-CONFIDENCE.md) and [PR #15](https://github.com/wefalltomorrow/UniExtract2/pull/15).
