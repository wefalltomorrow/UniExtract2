# Universal Extractor 2 v3.1.1

This release syncs the useful changes from gvp9000 v3.0.6 into the maintained wefalltomorrow fork without dropping the fixes added in v3.1.0.

## Changes

- fixed split Inno Setup installers on Unicode paths by copying external sidecar files such as `setup-1.bin` beside the temporary ASCII-named executable
- known QuickBMS/game extensions are no longer skipped just because another detector identifies the file as media
- silent mode automatically selects a BMS script only when exactly one script matches the extension
- ambiguous BMS matches are left alone instead of being guessed
- restores original Unix timestamps from Descent 3 HOG2 archives after successful QuickBMS extraction
- added bounds and output-path checks around HOG2 timestamp restoration
- improved pipeline result classification for innounp and common password, cancellation, disk-space and fatal-error output
- kept the v3.1.0 copied/quoted path fix, true-silent startup changes, MHTML extension recovery and fork-owned updater behavior
- release builds now verify the embedded version of all three executables
- full package now uses the gvp9000 v3.0.6 helper bundle instead of v3.0.4

## Packaging

The full ZIP is built on Windows with AutoIt 3.3.18.0. It starts from the gvp9000 v3.0.6 helper bundle, then overlays the executables, definitions, languages, documentation and metadata from this repository.

CI builds all three executables, verifies their file versions, creates the full package and runs extraction smoke tests before the release is published.

Helper updates still use gvp9000's maintained helper feed for now. Main UniExtract executable updates remain owned by this repository so the fork cannot be silently replaced by a different build.
